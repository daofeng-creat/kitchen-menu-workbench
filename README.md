# 厨房每周配菜工作台（Kitchen Weekly Menu Workbench）

一个 WorkBuddy 技能：把厨师的「历史菜单 .docx」解析成按品类分类的菜品库，
生成一个**单文件 HTML 工作台**——手机微信可直接打开，勾选本周上班日 → 一键自动配菜 → 一键复制纯文本菜单。

## 功能

- 勾选本周上班日（周一~周日），一键自动配菜。
- 严格按厨师历史菜单的 7 位结构出菜：**主荤×2 / 花荤×2 / 素菜×1 / 汤×1 / 水果×1**，位置不错位。
- 配菜硬约束：
  1. 水产（鱼/虾/贝等）每周 2~3 次；
  2. 本周主荤自动避开上周/下周（跨周不重复）；
  3. 同一周内主荤尽量不重复。
- 一键复制：输出与原始 Word 一致的极简格式（星期X 一行 + 7 道菜逗号连成一行以句号结尾）。
- 生成后可手动改菜：点任意菜名从品类库替换；也可输入新菜名，**自动加入菜库并持久保存**，下次生成随机出现（自定义鱼菜同样计入水产约束）。
- 数据存浏览器本地（localStorage），含导出/导入 JSON 备份。
- 零外部依赖、内联 SVG、移动端适配，微信内置浏览器可直接打开。

## 用法

```bash
# 默认读取当前目录「菜单.docx」，输出「厨房配菜工作台.html」
python3 assets/generate_workbench.py

# 自定义标题与署名
python3 assets/generate_workbench.py 菜单.docx -o 厨房配菜工作台.html \
    --title "抚州市教育体育局厨房每周配菜工作台" --author "何康"
```

生成的 HTML 可直接用浏览器打开；想放到手机微信里用，用 WorkBuddy 的「发布为应用」部署成 HTTPS 链接即可。

## 目录结构

```
kitchen-menu-workbench/
├── SKILL.md                      # 技能说明（触发词、工作流程、约束）
├── README.md                     # 本文件
├── example.html                  # 已生成的示例工作台（直接用浏览器打开看效果）
└── assets/
    ├── generate_workbench.py     # 解析 docx + 填充模板的生成器
    └── template.html             # 单文件工作台模板（含配菜引擎 + 移动端 UI）
```

## 菜单格式要求

历史菜单需符合：每天记录 7 道菜，顺序固定为
`主荤、主荤、花荤、花荤、素菜、汤、水果`，
且按「星期一…星期日」分天。脚本会自动清洗少量历史错位项。
